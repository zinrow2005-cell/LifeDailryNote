# 拾光記帳 Daybook V1.9.4｜手機、平板年度報表日期修正

## 本次修正

- 「年度分析報表」起始、結束年度改用精簡的 `民國 115 年` 文字，不再同時擠入西元年份；下拉選單的實際數值仍為西元年，不影響統計。
- 將「起始年度」「結束年度」標示為民國，以免誤解；改用彈性欄位避免年分被截斷。
- 600px 以下手機：「自訂精確日期區間」的開始、結束日期**上下排列，各占一整列**，避免 iOS／iPadOS 以民國格式顯示時被裁切。
- 601～1024px 平板：兩日期欄位平分整列並自動伸展，不再受舊版最大 160px 的限制。
- 按鈕換行及字體、最小觸控高度同步調整；保留日期選擇器功能與起訖日期驗證。
- 只調整版面與年度下拉選單文字，**不更動交易、分類、統計計算或 Google Apps Script 同步**。
- 更新網站、CSS／JS 及 Service Worker 快取至 V1.9.4。

## GitHub 更新

1. **先在現有系統匯出 JSON 完整備份**。
2. 解壓縮本 ZIP，將 `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest` 和 `icons/` 覆蓋 GitHub Pages 的原發布目錄。
3. GitHub Pages 發布後重新整理，確認左上角顯示 **V1.9.4**。
4. 手機及平板開啟「年度分析報表」檢查起始／結束年度與兩個日期輸入框，再嘗試自訂日期「套用日期」。

**Apps Script `Code.gs`、原本的 `/exec` 網址與私人金鑰均不用修改。** 既有 IndexedDB 記帳資料不會因前端更新被清除。

本版經 HTML/CSS 佈局與 JS 語法核對；如實體 iPhone／iPad Safari 的民國日期仍有裁切，請提供實機截圖，便於對應其原生日期控制項。
