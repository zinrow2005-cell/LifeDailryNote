# 拾光記帳 Daybook V1.9.5｜每日收支速覽

## 新增功能

- 總覽儀表板上方新增「每日收支速覽」，首次開啟預設為裝置今天的日期。
- 顯示所選日期的收入、支出、結餘與各類型筆數；沒有交易的日期顯示 NT$ 0。
- 左箭頭切換前一天，右箭頭切換下一天；**右箭頭最多只能切換到今天**，今天時會停用。
- 選到舊日期後可使用「回到今天」。
- 點選每日收入／支出／結餘金額，直接進入「收支明細查詢」，自動帶入該日期、收支類型（結餘為全部）。
- 日收支選擇**獨立於總覽的「本月、今年、去年、前年、近 12 個月」**範圍，不會互相干擾。
- 日期用裝置本地日期計算，支援跨月／跨年／閏年；資料新增、修改、匯入或下載後，總覽重新渲染時會更新。
- 手機雙欄排列收入與支出，結餘獨立一列，適應 320px 起小螢幕；平板及桌機維持三欄。

## 更新方式

1. 先在原版系統「資料備份與設定」匯出 JSON 完整備份。
2. 將壓縮包內的 `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest` 與 `icons/` 全部上傳原本 GitHub Pages 網站發布資料夾，覆蓋 V1.9.4。
3. 等待 GitHub Pages 發布，重新整理網站，確認標示版本為 **V1.9.5**。
4. 如仍看到舊版，請先關閉已開啟的 PWA 頁面後重新開啟。不要清除瀏覽器網站儲存資料，以免遺失本機帳目。

**Google Apps Script 不需要更新，原本 Google Sheets 同步網址及私人金鑰設定不變。**

## 測試及限制

- 已通過 `node --check` JavaScript 語法檢查。
- 已用 Chromium `set_content` 載入實際頁面 HTML＋CSS，並載入本次新增的 JS 功能做**隔離互動測試**：在 320、375、430、768、1366px 寬度，驗證日期切換、不可超過今天、收入／支出／結餘計算、點擊帶入明細篩選，以及橫向溢出檢查。
- 瀏覽器安全政策阻擋了 `http://localhost`、`file://` 的整站導覽，因此**尚未完成整套網站 IndexedDB、實際手機 Safari 和正式 Google Sheets 端到端測試**；請上傳後再用一筆測試記帳驗收。
- 本包未包含任何私人帳目、同步金鑰或測試帳目資料。
