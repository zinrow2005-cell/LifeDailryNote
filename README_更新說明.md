# 拾光記帳 Daybook V1.9.7 — 每日收支獨立與統計卡片明細

## 核心修改
- 總覽不再顯示每日收支，左側選單（手機下方導覽也有）新增「每日收支」。
- 每日收支支援日期前後移動（後一天不可超過今天）、當日收入、支出、結餘、分類與交易列表點擊查明細。
- 「本月」「今年」改用各自日期界線（本月 1 日～今天；當年 1 月 1 日～今天），並且顯示實際統計區間與筆數。如果當年只有本月交易，兩個期間總額相同是正確的，會顯示解釋提示。
- 收支總覽 KPI、收入性質、分類比例、趨勢柱狀圖、年度分析卡、年度表格、設定概況及預算支出卡片均可直接開啟帶日期條件的明細。
- 收支明細新增收入性質篩選，方便區分家庭移轉／借款與真正收入。

## 安全更新
1. 請先在舊版「資料備份與設定」匯出完整 JSON。
2. 到 GitHub 設定 Settings → Pages 確認發布分支和目錄（/ 或 /docs）。
3. 將本 ZIP **所有檔案連同 icons 資料夾**上傳到發布目錄根層，覆蓋舊檔；要確認 `index.html`、`app.v1.9.7.js`、`styles.v1.9.7.css`、`sw.js` 和 `version.json` 位於同層。不要把外層 ZIP 資料夾又包一層。
4. GitHub Actions / Pages 發布完成，開啟 `/check-update.html` 和主頁確認版本 V1.9.7。
5. 本版保留 `daybook_local_v1` IndexedDB 資料庫及現有 Google 同步設定，不需要重新設定 Apps Script。

重要：不清除瀏覽器網站資料。本壓縮檔不含使用者交易資料、Google Sheets ID 或私人金鑰。

## 驗證要點
- 點本月/今年時查看「選取期間」日期和筆數；若今年只有本月有資料，金額相同是正常情況。
- 點收支卡片，應跳至「收支明細查詢」且保留日期/類型篩選。
- 進入「每日收支」切換日期，不能瀏覽明天。
- 年度報表點年份合計、月份合計或累計統計，應能查明細。
- 正式 Google Sheets 雙向連線需在你自己的部署環境另行實測。
