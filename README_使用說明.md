# 拾光記帳 Daybook V1.5 — 預算與固定收支跨裝置同步

這是可部署至 GitHub Pages 的靜態 PWA。沿用 V1.4 的 UI、記帳、分類、搜尋、年度／區間分析及 IndexedDB 帳目資料；**不包含任何家庭真實交易**。

## V1.5 新功能

1. **預算跨裝置同步**：每個月份是一個獨立項目，包含總預算與分類預算。
2. **固定收支跨裝置同步**：每個模板獨立同步，連同啟用／暫停、略過的期別。確認入帳仍需手動操作，且實際記帳仍走原有交易同步流程。新版針對同一期固定帳單產生一致的交易 ID，降低不同裝置同時入帳產生重複明細的機會。
3. **離線待同步設定**：斷網仍可修改，登入後回到網站會嘗試同步。
4. **防止靜默覆蓋**：同一月份預算或同一模板在兩台裝置變更，會顯示「使用雲端／保留本機並上傳」選擇。這項保護使用資料庫原子版本檢查。
5. **備份與還原**：完整 JSON 含所有交易、分類、預算和固定收支，但不包含雲端密碼／金鑰；備份內容屬私人財務資料，勿上傳公開 Repository。
6. **手機版優化**：同一個頁面查看同步提示與衝突操作。

## 更新流程

1. **在 V1.4 先匯出完整 JSON**，保存到非公開位置。
2. 如果使用 Supabase，先到自己的 Supabase SQL Editor 執行 `SUPABASE_雲端同步建表.sql`（可重跑）。原有交易不會刪除。
3. 將本壓縮檔解壓縮後的 `index.html`、`app.js`、`styles.css`、`sw.js`、圖示與 manifest 等檔案放進原本的 GitHub Repository，**保持網址不變**。
4. 重新載入網站，如果仍顯示舊版可關閉重開 PWA／清除本網站「快取」而**不要清除網站資料／IndexedDB**。
5. 在原先的裝置先同步一次，再到其他裝置使用相同 Supabase 帳號登入並同步。

不啟用雲端也可離線正常記帳、設定預算及匯出備份。

## 同步資料的限制與安全

- Supabase **不是自動提供的服務**：你必須自行建立專案及執行 SQL。這版已以模擬遠端服務測試跨裝置流程，未實際連入你的 Supabase 專案。
- 雲端記帳內容受 RLS 管理，**不屬端對端加密**；請勿將 `secret`／`service_role` key 放進網站。
- V1.4 兩個裝置可能各自有不同預算；首次同步遇到同一項目但內容不同會保留本機並顯示衝突，由你選擇。
- 不同月份及不同固定收支可分開更新。**原有交易紀錄及分類同步仍依舊版的策略**；交易同 ID 同時編輯仍可能最後寫入者覆蓋，分類管理也是整組設定同步。
- 網站關閉後不會背景同步；網頁開啟期間約 75 秒、回到網頁、恢復連線，以及手動點「立即同步」時進行。
- 若雲端設定表未建好，交易可能已同步但預算同步失敗，畫面會顯示錯誤。
- 任何版本在升級／匯入／清除大量資料前，都先下載完整 JSON 備份。
