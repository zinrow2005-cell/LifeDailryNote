GOOGLE SHEETS SYNC

Google 試算表跨裝置同步 V1.6

使用你自己的 Google Sheets + Apps Script，電腦、手機、平板共用交易、分類、預算與固定收支。未設定時仍然可以離線記帳。

本機模式 · 未連線
預算與固定收支同步讀取設定…

同一筆設定在兩台裝置同時變更時，不會直接覆蓋。請選擇要保留哪一個版本。

目前沒有待處理的交易／分類衝突。

1 設定 Google Apps Script

先依壓縮檔「Google試算表同步設定指南」部署 Apps Script，再填入 /exec 網址。同步金鑰只保存於你自己的裝置，**不要上傳 GitHub**。

2 跨裝置記帳

在其他手機／平板開啟同一個 GitHub 網站，輸入相同的 Apps Script 網址與私人同步金鑰；兩端即可共用 Google 試算表資料。

同步不是持續即時推播：頁面開啟後、重新連線、返回頁面及按下「立即同步」時才會檢查。

請先將 V1.5 帳目匯出為 JSON 備份，首次連線前確認你的原本資料已保留。

尚未設定 · 資料只儲存在這台裝置

安全提醒：Google 試算表本身保持私人；Apps Script 以你的帳號執行時，必須搭配長隨機同步金鑰與受限網站來源。資料不是端對端加密。不要把 Apps Script 金鑰寫入 GitHub 程式檔，也不要開放試算表給任何人編輯。
